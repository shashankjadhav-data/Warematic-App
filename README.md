## "Warematic" Application Description
### 
A warehouse management system involves controlling and organizing the warehouse operations such as inventory management, pickup and delivery of stock and auditing. Our web application,” Warematic” aims at optimizing these processes by providing both the users and management an easy-to-use and manage application to ensure maximum efficiency.

## MVP Goals
### Our MVP goals include
* New Customer Sign-up
* Customer and Employee Log-in
* Customer Profile Creation
* Dashboard displaying: Information and Icons to navigate to services, warehouse.
* Services displaying: Information on new pickup order, new delivery order, my order, track order,process orders, notifications
* Customer is able to: create pickup order, create delivery order, view orders, track orders, view the list of goods available in the warehouse
* Clerk is able to: view notifications, process orders, view assigned pickup and delivery orders
